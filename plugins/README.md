# Plugins

Plugins register capabilities with `core.plugins.PluginRegistry`.

Supported capability buckets:

- `ocr_engines`
- `parsers`
- `medical_databases`
- `report_analyzers`
- `speech_engines`
- `translation_engines`
- `reminder_engines`
- `integrations`
- `ai_models`

See `examples/plugin_example.py`.
