# FHIR Guide

FHIR is the central clinical data model.

Supported resources include:

- Patient
- Practitioner
- Organization
- Encounter
- Medication
- MedicationRequest
- MedicationStatement
- Observation
- Condition
- AllergyIntolerance
- DiagnosticReport
- DocumentReference
- CarePlan
- Procedure
- Appointment
- ImagingStudy
- Bundle

Utilities live in `core/fhir`:

- validation
- serialization
- FHIR Bundle creation
- JSON import/export
