# OpenClinicalAI

OpenClinicalAI is a modular, open-source, FHIR-first clinical AI platform foundation.

It is designed for community contributions and future plug-in modules for OCR, prescription parsing, medical knowledge retrieval, clinical reasoning, safety validation, report analysis, and patient education.

## Start Locally

```bash
docker compose up
```

API documentation:

```text
http://localhost:8000/docs
```

## Core Ideas

- FHIR-first clinical data exchange
- Plugin-based AI modules
- Configurable model registry
- Secure-by-default platform hooks
- Dockerized services
- GitHub-ready contribution workflow
